# AGENTS.md - Agent Operating Guidelines

## Autonomous Execution Directives
1. **Pre-Granted Permissions:** All permissions are fully granted by the user to build, modify, test, and harden this project.
2. **Eliminate Permission Asking:** Never pause, prompt, or ask for user confirmation or permission to continue between phases, tasks, or milestones.
3. **Execute to Completion:** Once a task or phase plan is defined, execute each step sequentially without halting to request permission.
4. **No Confirmation Closings:** Do not end responses with conversational prompts asking "Confirm to proceed", "Shall I continue?", or "Whenever you are ready...".
5. **Quality & Zero Oscillation:** Follow zero-trust engineering, preserve append-only ledgers, maintain 100% test pass rates, and never oscillate on completed and locked phases.
